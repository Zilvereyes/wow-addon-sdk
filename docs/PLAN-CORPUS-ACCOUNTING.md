Status: implementation and focused checks are complete on a separate branch from XML PR #25; full acceptance is in progress. Starting point: `956ae83d7f7a919b198968d5fe1b43861e7fac8a`. The previous goal turn delivered XML syntax and evidence; merge of that PR remains a separate user decision. This increment addresses the existing acceptance requirement for honest per-language coverage. ## Observable defects and acceptance

1. TOC read and invariant failures currently collapse into one Set reason. Add `tocAnalysis` with discovery/completeness, discovered/attempted/submitted/completed, accepted/rejected, skipped-oversized/resource, read/backend/invariant failures and successfully read input bytes. Keep existing `files`, `parsed`, diagnostic and skip fields. Submitted means a parser invocation; completed means it returned. Only a fully validated syntax verdict increments parsed; syntax diagnostics remain rejected verdicts, not transport failures.
2. Lua lacks a per-file invariant counter and can credit parsed/diagnostic/declaration metrics before validating later declarations. Add invariantFailures and discoveryComplete; validate the whole result before committing its metrics. Two invalid projections must produce exactly two invariant failures, zero parsed credit for either, no leaked partial diagnostics/activations and incomplete nonzero status.
3. TOC currently checks size before an unbounded readFileSync, then checks again after allocation. Replace that path with a private tooling helper using read-only open, bounded buffers/reads, final-component link checks and stable bigint file identity/size/nanosecond times. It must reject growth, replacement, shrinkage and native read failure without parsing changed input; every owned descriptor must close. Use nonblocking open where supported to reject a substituted FIFO before a blocking open. Preserve original bytes and existing TOC string decoding rather than choosing a new codec.
4. Discovery and language processing remain independent: truncated/blocked traversal prevents completeness for every enabled language, while an unrelated TOC error cannot invalidate fully enumerated XML. Existing strict XML behavior and Lua corpus transport/profile limits remain unchanged.
